05.10.2026 полный запуск завершился с кодом 0 на Ubuntu 24.04.5 LTS, x86_64. Домены, IP, имена ноды и UUID из тестовой среды исключены из репозитория.

| Панель | Профиль, нода, хост созданы; нода подключена без ошибки Xray |

Повторные запуски использовали существующие объекты панели. Существующие рабочие Internal Squads не изменялись; тест использовал отдельную группу. При сбое проверки ядра автоматическое восстановление прежнего ядра также сработало на VPS.

## Границы проверки

Проверены установка и соединение, без оценки скорости или устойчивости к блокировкам. Не проверялись работа после перезагрузки, будущее продление ACME-сертификата, внешний webhook и firewall провайдера. Пакеты Docker устанавливать не потребовалось: использована уже имеющаяся установка.

Другая архитектура CPU, новая версия панели/ноды и недоступный DNS-over-TLS upstream требуют отдельной проверки. Установленные пакеты могут потребовать перезагрузку VPS; установщик сообщает об этом и не выполняет её автоматически.
